# EventSpace

_Система управления мероприятиями / платформа для создания и регистрации на события_

EventSpace — это веб-приложение для организации мероприятий, регистрации участников, просмотра афиши и управления событиями. Проект разрабатывается в рамках учебного курса по ИТ и веб-программированию в БГУИР.

## Технологии

- **Backend**: Node.js + Express
- **Frontend**: HTML / CSS / JavaScript

- **Дополнительно**:

  - Prettier — форматирование кода
